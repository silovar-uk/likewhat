DESIGN DECISION WORKBENCH

「何を参考にするか」を、
早く決める。

Like What? は、デザインを眺めて終わるギャラリーではありません。いま抱えている課題から事例を探し、違いを見て、使えそうなものを案件ごとに残し、自分の設計方針へ変えるための参照ワークベンチです。

⌕ ⌘ K

START FROM THE PROBLEM

いま、何を良くしたい？

ブランド名が思い浮かばなくても大丈夫。まず案件側の悩みを選ぶと、課題に近い参照を出します。見つけたものは「参考」に残し、2件なら即比較、複数なら設計方針へまとめられます。

課題をひとつ選ぶ。

「情報を整理したい」「スマホ操作を改善したい」など、作っているもの側の困りごとから参照を引きます。

LEARNING PATH / 学び方
参照を、判断できる知識にする。

          
初回だけ少し丁寧に。事例を見つけ、気になった違いに名前をつけ、比較して判断軸をつくり、最後に自分の実装へ変換する。再訪時は、この説明を畳んで作業から始められます。

        

        
    
          
  1. 01見つける
    ブランド名や場面から事例を探し、「何が気になるか」を見つける。
    ライブラリを見る
    2. 
          
  2. 02言葉にする
    WorldbuildingやWayfindingなど、感覚に名前を与えて再利用できる知識にする。
    語彙で確かめる
    3. 
          
  3. 03比べる
    似ているもの・遠いものを並べ、「何を優先すると違いが生まれるか」を読む。
    違いを比べる
    4. 
          
  4. 04使う
    理解した特徴を、色の模倣ではなく情報階層や操作の条件として持ち帰る。
    参考を束ねる

実務に持ち帰る / COMPOSE
「何っぽく」×「どの場面？」
単体の参照から考えたいときはこちら。2つの参照を色で平均するのではなく、情報階層・距離感・操作・感情強度を組み合わせ、実装できる条件へ変換する。

いつもの好みだけを見続けないための寄り道。偶然、距離、異質さの3通りで参照を引き、知らない判断軸に出会う。
