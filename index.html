デザインを「見る」で終わらせない

「こんな感じ」を、
説明できる力に変える。

Like What? は、見た目を集めるギャラリーではなく、デザインを観察し、言葉にし、比べ、実務へ持ち帰るための学習ライブラリ。ブランド名を覚えるのではなく、「なぜそう見えるのか」「どこで使えるのか」を考えるための道具です。

⌕ ⌘ K

LEARNING PATH / 学び方

見る → 言う → 比べる → 使う。

全部の機能を覚える必要はありません。まず事例を見つけ、気になった違いに名前をつけ、比較して判断軸をつくり、最後に自分の実装へ変換する。この4段階を行き来するほど、参照が「知識」に変わります。

  1. 01見つける

    ブランド名や場面から事例を探し、まず「何が気になるか」を見つける。

    ライブラリを見る
  2. 02言葉にする

    WorldbuildingやWayfindingなど、感覚に名前を与えて再利用できる知識にする。

    語彙で確かめる
  3. 03比べる

    似ているもの・遠いものを並べ、「何を優先すると違いが生まれるか」を読む。

    違いを比べる
  4. 04使う

    理解した特徴を、色の模倣ではなく情報階層や操作の条件として実装へ持ち帰る。

    Briefを作る

迷ったら、知りたいことから選ぶ。

機能名を覚えるより、「全体像を見たい」「言葉を増やしたい」「違いを判断したい」から入口を選ぶ。

実務に持ち帰る / COMPOSE

「何っぽく」×「どの場面？」

2つの参照を色で平均するのではなく、情報階層・距離感・操作・感情強度を組み合わせ、実装できる条件へ変換する。
