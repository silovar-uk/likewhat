Coverage Plannerの計算方法 Method / explainability

Coverage Delta：ビルド時に生成したWave 3直前63件／Wave 3時点78件のcompact snapshotへ同じ指標を適用する。現在の163件とは分離して履歴比較を固定する。

Spatial Gap：6軸を10 / 50 / 90の3値に離散化した729点について、現在の163件への最短Design Distanceを計算。近接した候補点を間引き、異なる空白方向を残す。

Brand / Era：トップ一覧ではILLITやCHANMINAを1アーティストとして束ねるが、Era / Conceptは異なる設計原則を持つため、Design Space上では別Patternとして保持する。

Institution：大学は校章やスクールカラーではなく、権威・研究・学生生活・公共性・未来志向などの設計配分として同じ6軸へ置く。

Scene：Loading / 404 / Empty / Error / Success / Onboardingはブランド横断の状態パターンとして保持し、「何が起きているか」「どう復帰・継続するか」を比較する。

Industry Cluster：Eyewearのように同じ業界・近い設計問題を扱うブランドは、ブランド数ではなく1つのCluster referenceとしてDesign Spaceへ置く。Cluster内部の差は詳細ページで保持する。

Thin Vocabulary：各語彙に接続するPattern数・ブランド数・Domain数を数え、実例数が少なく単一ブランド / 単一Domainに偏るほど優先度を上げる。

Research Priority：Spatial 55% + Concept 25% + Context 20%。これは「追加価値」を決める絶対スコアではなく、調査順序を作るための編集的ヒューリスティック。
